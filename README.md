# Better Pause Menu

Adds a single QoL Hub under Pause > Options with:
- Current planet
- Health and bolts
- Restart current planet
- Skip current in-level cutscene

It intentionally uses only one of OpenRAC's two mod pause-menu slots.

Built for OpenRAC RAC1 PAL/NTSC-U. AI-assisted implementation. GPL-3.0-or-later.
